# Task 2 - Unemployment Analysis with Python

## 📌 Project Overview
This project focuses on analysing unemployment trends in India using Python. The analysis explores regional unemployment rates, monthly trends, and the impact of the COVID-19 pandemic on employment.

## 🎯 Objectives
- Analyse unemployment rates across different Indian regions.
- Identify monthly unemployment trends.
- Compare unemployment rates across selected states.
- Study the relationship between employment indicators.
- Compare pre-COVID and post-COVID unemployment rates.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## 📂 Dataset
**Dataset:** Unemployment in India

**Source:** [Kaggle - Unemployment in India](https://www.kaggle.com/datasets/gokulrajkmv/unemployment-in-india)

The dataset contains information about:
- Region
- Date
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area

## 📊 Analysis Performed
1. Data loading and cleaning.
2. Regional average unemployment analysis.
3. Monthly unemployment trend visualization.
4. State-wise unemployment comparison (Maharashtra, Uttar Pradesh, and Tamil Nadu).
5. Top 10 regions with the highest average unemployment.
6. Correlation heatmap of employment indicators.
7. Pre-COVID vs Post-COVID unemployment comparison.

## 🔍 Key Findings
- Tripura recorded the highest average unemployment rate (28.35%).
- Meghalaya recorded the lowest average unemployment rate (4.80%).
- Tamil Nadu showed the sharpest increase among the three selected states around April–May 2020.
- The average unemployment rate increased from 9.51% before COVID-19 to 17.77% after March 2020.

## 📝 Conclusion
The analysis revealed significant regional differences in unemployment across India. It also highlighted a sharp increase in unemployment during the COVID-19 period. Data visualization helped identify important trends and understand the changes in India's unemployment situation.
