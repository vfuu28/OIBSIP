# Task 1: Iris Flower Classification

## Overview
This project focuses on building a Machine Learning model to classify iris flowers into three species: Setosa, Versicolor, and Virginica.

## Objective
To predict the species of an iris flower using its sepal and petal measurements.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Exploratory Data Analysis
- Dataset overview and descriptive statistics
- Missing value analysis
- Species distribution
- Pairplot and boxplot visualisations
- Feature correlation heatmap

## Machine Learning Models
1. Logistic Regression
2. K-Nearest Neighbors (KNN)

## Model Performance

| Model | Accuracy |
|---|---:|
| Logistic Regression | 96.67% |
| KNN | 93.33% |

## Best Performing Model
Logistic Regression achieved the highest accuracy of 96.67% and was selected as the best-performing model.

## Conclusion
The project demonstrates how Machine Learning can classify iris flower species using their physical measurements. Both models were evaluated, and Logistic Regression achieved better performance on the test dataset.
