# Iris Flower Classification

## Oasis Infobyte Data Science Internship – Task 1

### Project Overview
This project focuses on building a Machine Learning classification model to predict the species of an Iris flower based on its physical measurements.

The Iris dataset contains three species:
- Setosa
- Versicolor
- Virginica

### Objective
To explore the Iris dataset, perform Exploratory Data Analysis (EDA), visualise feature relationships, train classification models, and compare their performance.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

### Project Workflow
1. Loaded the built-in Iris dataset using Scikit-learn.
2. Performed EDA to understand the dataset's structure and features.
3. Checked missing values and generated descriptive statistics.
4. Created visualisations using pairplots, boxplots, and a correlation heatmap.
5. Split the dataset into 80% training data and 20% testing data.
6. Trained two classification models:
   - Logistic Regression
   - K-Nearest Neighbors (KNN)
7. Evaluated both models using accuracy, confusion matrices, precision, recall, and F
